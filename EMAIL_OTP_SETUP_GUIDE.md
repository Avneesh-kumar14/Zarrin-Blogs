## 🔧 BACKEND SETUP

### Step 1: Install Dependencies

```bash
cd Zarrin_server
npm install
```

This installs `nodemailer` for email sending.

### Step 2: Configure Environment Variables

Create or update `.env` file with these **NEW** email settings:

```env
# Gmail App Password (NOT your regular Gmail password)
EMAIL_USER=your_email@gmail.com
EMAIL_PASSWORD=your_16_digit_app_password

# Other existing variables...
PORT=8200
MONGO_URL=your_mongodb_url
JWT_SECRET=your_secret
```

### Step 3: Get Gmail App Password (CRITICAL!)

1. **Enable 2-Factor Authentication:**
   - Go to https://myaccount.google.com/security
   - Click "2-Step Verification"
   - Follow setup

2. **Generate App Password:**
   - Go to https://myaccount.google.com/apppasswords
   - Select: Mail and Windows Computer
   - Google generates a 16-character password
   - Copy this password to `.env` as `EMAIL_PASSWORD`

**⚠️ Important:** 
- Never use your actual Gmail password in `.env`
- Always use the App Password generated by Google
- The App Password is 16 characters with spaces

### Step 4: Test Locally

```bash
npm run dev
```

## 📱 FRONTEND SETUP - NEW ENDPOINTS

### Signup Flow (3 Steps)

**Step 1: Signup (Send Email)**
```javascript
POST /api/auth/signup
{
  "name": "John Doe",
  "email": "john@example.com",
  "password": "SecurePass@123"
}

Response:
{
  "message": "Signup successful! OTP has been sent to your email.",
  "email": "john@example.com",
  "requiresVerification": true
}
```

**Step 2: Verify OTP (Confirm Email)**
```javascript
POST /api/auth/verify-otp
{
  "email": "john@example.com",
  "otp": "123456"  // 6-digit code from email
}

Response:
{
  "message": "Email verified successfully!",
  "user": { ... },
  "token": "jwt_token_here"
}
```

**Step 3: Resend OTP (If needed)**
```javascript
POST /api/auth/resend-otp
{
  "email": "john@example.com"
}

Response:
{
  "message": "New OTP has been sent to your email. Valid for 10 minutes.",
  "email": "john@example.com"
}
```

### Login Flow (Updated)

```javascript
POST /api/auth/login
{
  "email": "john@example.com",
  "password": "SecurePass@123"
}
```

## 🎨 FRONTEND COMPONENTS TO UPDATE

### Update Signup Page

```jsx
import { useState } from 'react';

const SignupPage = () => {
  const [step, setStep] = useState(1); // 1: signup, 2: verify
  const [email, setEmail] = useState('');
  const [name, setName] = useState('');
  const [password, setPassword] = useState('');
  const [otp, setOtp] = useState('');
  const [loading, setLoading] = useState(false);

  // Step 1: Send OTP
  const handleSignup = async (e) => {
    e.preventDefault();
    try {
      setLoading(true);
      const res = await fetch('/api/auth/signup', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ name, email, password })
      });
      const data = await res.json();
      
      if (res.ok) {
        setStep(2); // Move to verification
      } else {
        alert(data.message);
      }
    } finally {
      setLoading(false);
    }
  };

  // Step 2: Verify OTP
  const handleVerifyOTP = async (e) => {
    e.preventDefault();
    try {
      setLoading(true);
      const res = await fetch('/api/auth/verify-otp', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ email, otp })
      });
      const data = await res.json();
      
      if (res.ok) {
        // Save token and redirect to dashboard
        localStorage.setItem('token', data.token);
        window.location.href = '/dashboard';
      } else {
        alert(data.message);
      }
    } finally {
      setLoading(false);
    }
  };

  // Resend OTP
  const handleResendOTP = async () => {
    try {
      setLoading(true);
      const res = await fetch('/api/auth/resend-otp', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ email })
      });
      const data = await res.json();
      alert(data.message);
    } finally {
      setLoading(false);
    }
  };

  return (
    <div>
      {step === 1 ? (
        <form onSubmit={handleSignup}>
          <input
            type="text"
            placeholder="Full Name"
            value={name}
            onChange={(e) => setName(e.target.value)}
            required
          />
          <input
            type="email"
            placeholder="Email"
            value={email}
            onChange={(e) => setEmail(e.target.value)}
            required
          />
          <input
            type="password"
            placeholder="Password (min 8 chars, uppercase, lowercase, number, special char)"
            value={password}
            onChange={(e) => setPassword(e.target.value)}
            required
          />
          <button type="submit" disabled={loading}>
            {loading ? 'Sending OTP...' : 'Send OTP to Email'}
          </button>
        </form>
      ) : (
        <form onSubmit={handleVerifyOTP}>
          <p>📧 OTP sent to: {email}</p>
          <input
            type="text"
            placeholder="Enter 6-digit OTP"
            value={otp}
            onChange={(e) => setOtp(e.target.value.slice(0, 6))}
            maxLength="6"
            required
          />
          <p style={{ fontSize: '12px', color: '#666' }}>
            ⏱️ OTP expires in 10 minutes
          </p>
          <button type="submit" disabled={loading}>
            {loading ? 'Verifying...' : 'Verify OTP'}
          </button>
          <button
            type="button"
            onClick={handleResendOTP}
            disabled={loading}
            style={{ marginTop: '10px' }}
          >
            Resend OTP
          </button>
        </form>
      )}
    </div>
  );
};

export default SignupPage;
```

## 🆘 TROUBLESHOOTING

### **Issue: Emails not being sent**

**Solution:**
1. Check EMAIL_USER is correct Gmail address
2. Check EMAIL_PASSWORD is 16-char app password (NOT Gmail password)
3. Check 2FA is enabled on Google account
4. Check no typos in .env
5. Restart server: `npm run dev`

### **Issue: OTP not received**

**Solution:**
1. Check spam/promotions folder in Gmail
2. Check EMAIL_USER is sending to correct address
3. Try resend OTP
4. Check server logs for email errors

### **Issue: OTP expires too quickly**

**Current setting: 10 minutes**
To change, edit `/Zarrin_server/routes/auth.js`:
```javascript
// Line: const otpExpires = new Date(Date.now() + 10 * 60 * 1000);
// Change 10 to desired minutes:
const otpExpires = new Date(Date.now() + 15 * 60 * 1000); // 15 minutes
```
