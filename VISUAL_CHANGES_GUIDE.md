## 🎯 Design Consistency

### Color Pattern
Every gradient appears in this order:
1. Homepage sections
2. Blog page sections
3. Cards throughout
4. Buttons and CTAs
5. Footer elements

### Shadow Pattern
- Light: `shadow-sm` (hover states)
- Medium: `shadow-md` (interactive elements)
- Heavy: `shadow-lg` (default cards)
- Extra: `shadow-xl` (featured sections)
- Hover: `shadow-2xl` (enhanced on interaction)

### Animation Pattern
- Duration: 200-500ms for all transitions
- Delay: 2s-4s for blob animations
- Scale: 1.05x-1.1x for hover effects
- Opacity: 0-1 for fade effects
